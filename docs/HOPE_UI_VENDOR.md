# Hope UI vendored stylesheet

The admin stylesheet files under `public/admin-assets/css/` were retrieved from the official [Hope UI HTML Admin Dashboard](https://github.com/iqonicdesignofficial/hope-ui-html-admin-dashboard), commit `51e0e0675e817f1c9891e79b92715db78336ff40` (`package.json` version `4.0.0`).

Files: `dist/assets/css/hope-ui.min.css`, `dist/assets/css/core/libs.min.css`.

Original Hope UI/Bootstrap structure is preserved in Laravel Blade. Toward HIM custom styles load **after** Hope UI in `toward-admin.css`, retaining the approved orange and cream brand. The source project is MIT-licensed; preserve attribution in distributed builds.
